# FitFuel

Premium, conversion-first website for FitFuel — a disciplined South African fitness brand.

## Stack
- Next.js (App Router) + TypeScript
- TailwindCSS
- Framer Motion
- shadcn/ui (button primitives)

## Getting Started
Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts
- `npm run dev` — Start Next.js dev server
- `npm run build` — Build for production
- `npm run start` — Start production server
- `npm run lint` — Lint with Next.js config

## Content & Data
- `src/content/copy.ts` contains all editable copy.
- `src/data/products.ts` contains placeholder product data and size guide.

## Deployment
Deploy to Vercel or any Node.js host supporting Next.js.
